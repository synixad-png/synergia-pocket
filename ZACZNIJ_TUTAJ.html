SYNERGIA POCKET · WEB v3

Uruchom na telefonie.

Konfiguracja tylko raz. Później wchodzisz na własny adres HTTPS i wpisujesz login oraz hasło do Synergii.

Ważne: tej strony nie używasz do wpisywania hasła Librus. To wyłącznie instrukcja. Login i hasło wpiszesz dopiero w swojej uruchomionej aplikacji HTTPS.

1 Załóż repozytorium GitHub

Kliknij przycisk. Na GitHub utwórz repozytorium o nazwie synergia-pocket. Ustaw Private i nie dodawaj README, licencji ani .gitignore. Następnie kliknij Create repository.

Otwórz GitHub — nowe repozytorium

2 Prześlij gotowy kod

Rozpakuj ZIP SYNERGIA_POCKET_WEB_v3_GOTOWE_DO_HOSTINGU.zip. W nowym repozytorium wybierz uploading an existing file, przeciągnij wszystkie pliki i foldery z rozpakowanej paczki i kliknij Commit changes.

Najważniejsze pliki: app.py · demo.py · Dockerfile · render.yaml · requirements.txt · folder static/

Na komputerze wygodniej przeciągnąć cały zestaw plików. Na telefonie GitHub może nie pozwolić przesłać katalogów.

Możesz zmienić nazwę, jeśli utworzone repozytorium nazywa się inaczej.

Otwórz ekran przesyłania kodu

3 Uruchom serwer w Render

Kliknij przycisk, połącz Render z GitHub i daj dostęp do utworzonego repozytorium. Sprawdź konfigurację: Free oraz SYNERGIA_FORCE_HTTPS = 1. Jeśli usługa Free nie jest oferowana, nie zatwierdzaj płatnego planu bez sprawdzenia ceny.

Deploy to Render — opublikuj stronę

Alternatywnie na Render Dashboard wybierz New → Blueprint i wskaż repozytorium. Render zbuduje Python automatycznie.

4 Otwórz na telefonie

Gdy Render pokaże stan Live, skopiuj otrzymany adres https://...onrender.com, otwórz go na telefonie i wpisz login Synergia (np. 1234567u) oraz hasło Synergia.

Nie używaj danych do Konta LIBRUS, jeśli różnią się od danych Synergia. Działanie prawdziwego logowania pozostaje do sprawdzenia na Twoim koncie.

Android Chrome: ⋮ → Dodaj do ekranu głównego. iPhone Safari: Udostępnij → Do ekranu początkowego.

To niezależna, niezaudytowana aplikacja testowa. Nie jest oficjalnym programem Librus. Udostępnienie serwera w internecie wymaga zachowania szczególnej ostrożności ze względu na dane uczniów.
